## 项目介绍
‌[Trino‌](https://github.com/trinodb/trino) 是一个快速的分布式 SQL 查询引擎，主要用于大数据分析。

**核心特性：**
 - **分布式架构‌：** TrinoDB采用分布式架构，能够充分利用集群中的计算资源，实现高效的并行查询处理。
 - **多数据源支持‌：** 支持连接多种数据源，包括大数据存储系统、关系数据库等，提供统一的数据访问接口。
 - **‌高性能查询‌：** 通过优化的查询计划和执行引擎，实现快速的数据分析和查询响应。
 - **标准SQL支持‌：** 提供标准的SQL查询语言，降低用户学习成本，提高开发效率。
 - **‌可扩展性‌：** 支持自定义连接器，方便用户扩展TrinoDB以支持更多的数据源。



本项目提供的开源镜像商品 [**Trino分布式SQL查询工具**](https://marketplace.huaweicloud.com/hidden/contents/250153e3-70a7-47bf-bd63-ed25f6001add#productid=OFFI1128523777590206464)，已预先安装 Trino 软件及其相关运行环境，并提供部署模板。快来参照使用指南，轻松开启“开箱即用”的高效体验吧。

> **系统要求如下：**
> - CPU: 2GHz 或更高
> - RAM: 4GB 或更大
> - Disk: 至少 40GB
